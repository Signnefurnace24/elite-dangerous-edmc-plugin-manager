## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Plugin List** | Browse installed EDMC plugins with version and status info |
| **Update Tracker** | Flag outdated EDMC plugins with available updates |
| **Data Settings** | Configure which data EDMC shares per plugin and destination |
| **Config Profiles** | Save named EDMC configurations for different gameplay modes |
